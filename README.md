**My Finance Tracker**

This is the first project I have made which I have connected to GitHub services as a way to improve my Python as well as learn to use Git. 
This project is still in progress.

I wanted to create this project for myself and others to use during their time at University. Knowing that handling finances can be troublesome
for people my age, this project was aimed to help alleviate this issue. Now, I can see my spending habits visually which helps me budget.

This project was programmed using Python; using the DateTime and MatPlotLib libraries, I was able to create a functioning project.

Project functionalities:

* Import a .csv file containing financial data (such as income, expense, category of expense, a description etc.)
* Run the project. This totals up all income and expenses as well as displaying the data visually via graphs.
* Version Control: Git / GitHub
* Core concepts: OOP (encapsulation, instantiation, classes and objects
